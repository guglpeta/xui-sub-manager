# xui-sub-manager

Набор консольных утилит для управления JSON-подписками 3x-ui, склейки их с собственными прокси и импорта сторонних подписок с раздачей через Nginx (оптимизировано для клиента Happ).

## Возможности
* **Склейка подписок (`merge-json.sh`)** — объединяет стандартную подписку 3x-ui с личными HTTP/HTTPS/SOCKS5-прокси (`add-proxy.sh`, `proxies.sh`)[cite: 2, 4, 8] и сторонними подписками.
* **Группы серверов и клиенты (`groups.sh`, `clients.sh`)** — распределение прокси и серверов 3x-ui по группам, индивидуальные названия (`profile-title`), описания (`announce`) и привязка групп к `subId` клиентов[cite: 1, 2, 9].
* **Импорт и заморозка чужих подписок (`freeze-sub.sh`, `sublinks.py`)** — скачивание и ретрансляция сторонних подписок в режимах заморозки или автообновления (в том числе до конца срока действия)[cite: 10], поддержка `x-hwid`[cite: 10], скачивание через прокси[cite: 10], переименование/отключение серверов[cite: 6, 10] и очистка длинных списков доменов маршрутизации[cite: 10].
* **Сортировка серверов (`order-sub.sh`)** — настройка точного порядка отображения серверов в приложении Happ для каждого клиента[cite: 3].
* **Единое меню (`sub.sh`)** — интерактивный интерфейс для управления всеми модулями[cite: 5].

## Установка

1. Клонируйте репозиторий на сервер (Ubuntu/Debian) и запустите установщик:
```bash
git clone [https://github.com/guglpeta/xui-sub-manager.git](https://github.com/guglpeta/xui-sub-manager.git)
cd xui-sub-manager
sudo bash install.sh
```
2. Добавьте директивы из examples/nginx-site.conf в ваш конфиг Nginx и перезагрузите его (nginx -t && systemctl reload nginx).

3. Запустите панель управления:
```bash
sub.sh
```

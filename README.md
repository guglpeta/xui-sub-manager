# xui-sub-manager

Набор консольных утилит для управления JSON-подписками, склейки их с собственными прокси и импорта сторонних подписок с раздачей через Nginx (оптимизировано для клиента Happ). Может работать как в связке с **3x-ui**, так и полностью автономно (**standalone**).

## Возможности
* **Склейка подписок (merge-json.sh)** — объединяет личные HTTP/HTTPS/SOCKS5-прокси (dd-proxy.sh, proxies.sh), импортированные подписки и (опционально) подписку 3x-ui в единый JSON-профиль.
* **Группы серверов и клиенты (groups.sh, clients.sh)** — распределение серверов по группам, индивидуальные названия (profile-title), описания (nnounce) и привязка групп к subId клиентов.
* **Импорт и заморозка чужих подписок (reeze-sub.sh, sublinks.py)** — ретрансляция сторонних подписок в режимах заморозки или автообновления (в том числе до конца срока действия), поддержка x-hwid, скачивание через прокси, переименование/отключение серверов и очистка длинных списков доменов маршрутизации.
* **Сортировка серверов (order-sub.sh)** — настройка точного порядка отображения серверов в приложении Happ для каждого клиента.
* **Единое меню (sub.sh)** — интерактивный интерфейс для управления всеми модулями.

## Быстрая установка

Установщик сам поставит зависимости (jq, python3, 
ginx, certbot), настроит виртуальный хост Nginx, выпустит SSL-сертификат и добавит задачи в cron:

```bash
git clone https://github.com/guglpeta/xui-sub-manager.git
cd xui-sub-manager
sudo bash install.sh
```

После установки запустите панель управления:
```bash
sub.sh
```
